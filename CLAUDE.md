# askeza

Приложение для отказа от вредных привычек. Помогает отслеживать время без привычки,
видеть, как слабеет тяга, проходить фазы восстановления и держать аскезы — обеты
воздержания на конкретный срок.

## Структура репозитория

```
index.html            — askeza 1 (v1.4.0). ЗАМОРОЖЕНА. Не трогать.
apple-touch-icon.png  — иконка v1
askeza2/              — askeza 2 (v2.0). Активная разработка
  index.html            весь код приложения (HTML + CSS + JS)
  sw.js                 service worker — офлайн
  manifest.webmanifest  PWA-манифест
  icon-180.png          иконка для iOS (37 КБ)
  icon-512.png          иконка для манифеста
  tests/run.mjs         309 автотестов (Playwright)
V2.md                 — ревью v1 и план v2
CLAUDE.md             — этот файл
```

**Важно:** `index.html` в корне — это старое приложение. Оно заморожено и работает
по-прежнему. Вся работа идёт в `askeza2/`.

# askeza 2 — активная версия

**Текущая версия: `v2.1`**

## Стек

- Single-file PWA (HTML + CSS + JS в одном `askeza2/index.html`), ноль зависимостей
- Системный шрифт (`-apple-system` / SF Pro) — никаких внешних запросов
- Данные: `localStorage`, полностью на устройстве
- Целевая платформа: нативное iOS-приложение (App Store)

## Два архетипа привычки

Привычки разного формата не помещаются в одну механику, поэтому их две.
Архетип задаётся типом привычки (`KINDS[kind].mode`), а не отдельным полем.

| | **Отказ** (`abstain`) | **Режим** (`daily`) |
|---|---|---|
| Типы | курение, алкоголь, марихуана, скроллинг, порно, своя | режим сна |
| Серия | непрерывный таймер с даты отказа | дни подряд с отметкой |
| Обрывается | срывом | проспанным или пропущенным днём |
| Главный экран | одометр, тяга, фаза | отметка дня, календарь, статистика |
| Кнопка «Тянет» | есть | нет |

Общее для обоих: кольцо аскезы, вехи, история, экспорт. Аскеза «30 дней» в режиме —
это 30 дней подряд без пропусков; прогресс считается серией, а не временем.

## Модель данных

```js
habit = {
  id, name,
  kind: 'smoking'|'alcohol'|'weed'|'scroll'|'porn'|'sleep'|'custom',  // тип, а НЕ регулярка
  color, emoji,
  startedAt,                                          // начало серии / старт режима
  sid,                                                // номер серии: растёт при срыве
  vow: { days, startedAt, endsAt, status } | null,    // активная аскеза
  daily: { wakeBy:'07:00', checks:{ 'YYYY-MM-DD':{ok,at} } },   // только у режима
  history: [                                          // всё, что было
    { t:'start',     at },
    { t:'relapse',   at, streakDays, note? },
    { t:'milestone', at, key, sid|from, seen },
    { t:'vow_done',  at, days, from, seen },
    { t:'vow_fail',  at, days, from, onDay },
    { t:'urge',      at },                            // нажатие «Тянет»
    { t:'wake',      at, day, time },                 // встал вовремя
    { t:'oversleep', at, day, time },                 // проспал
    { t:'legacy',    at, label, note },               // перенос из askeza 1
  ],
}
```

Срыв **не стирает** вехи из истории: они помечены номером серии (`sid`), а новая серия
зарабатывает их заново. У режима вехи привязаны к дню начала серии (`from`) —
поэтому правка отметки задним числом пересчитывает их сама.

Ключи хранилища: `askeza2_data` (основной), `askeza2_backup` (автокопия).
`askeza_data` — данные старого приложения, **только чтение**, никогда не пишем.

## Один принцип прогресса

**Фазы = где ты сейчас. Вехи = что ты прошёл. Аскеза = что ты обещал.**

Три сущности, три разных вопроса, никакого пересечения. Римские цифры и тиры
(бронза/серебро/золото/платина) принадлежат **только фазам**. Вехи — датированные
события в истории, у них нет рангов.

## Что реализовано

### Ядро
- Несколько привычек, переключение через меню, редактирование, удаление
- Тип привычки задаётся при создании и переживает переименование
- Календарно корректный отсчёт (настоящие месяцы, не «30 дней»)
- Русская плюрализация везде (`1 день`, `21 день`, `22 дня`, `25 дней`)
- Экранирование пользовательского ввода, обработчики через делегирование
- Экспорт/импорт JSON, автоматическая резервная копия, восстановление из битого хранилища
- Автоперенос из askeza 1 при первом запуске (старые данные не меняются)

### Главный экран
- Кольцо аскезы — герой экрана. Без обета — пунктирная заглушка с числом дней
- Карточка тяги с живым числом (10 Гц, динамическая точность) и зоной
- Одометр: 6 полос с непрерывно текущей секундной
- Карточка текущей фазы, кнопка «Тянет», карточка истории, цитата
- Фон подкрашивается цветом текущей фазы и плавно перетекает при её смене

### Аскеза
- Обет на срок: пресеты 7/21/30/40/100 + произвольный (1–999)
- Отсчёт **с даты отказа** — уже пройденное засчитывается
- Финиш определяется сравнением времени: срок, истёкший при закрытом приложении,
  всё равно празднуется, с правильной датой
- После финиша: продлить (с момента окончания прошлого), новый срок, без срока
- Срыв обрывает и серию, и аскезу; обе попадают в историю

### Режим сна
- Цель: встать до заданного времени. Одна кнопка «Я проснулся» фиксирует время сама
- Серия = дни подряд; незакрытый сегодняшний день серию не обрывает — он ещё идёт
- Пропущенные дни можно закрыть задним числом за последние трое суток
- Календарь на пять недель, статистика: вовремя / проспал / средний подъём
- Точное время подъёма правится на отдельном экране дня

### Тяга (курение / алкоголь / марихуана)
- Кривые построены на опорных точках из исследований, интерполяция PCHIP
  в лог-пространстве дней: монотонная, проходит точно через данные
- Курение переведено с формулы `99/√(1+дни)+1` на опорные точки: пик держится
  первые 1–3 дня, как в реальных данных
- График: два слоя канваса (статический + живая точка), реальный DPR

### Фазы
- 8 фаз у курения и алкоголя, 7 у марихуаны, скроллинга и порно — с рангами и тирами
- Описания видны у **всех** фаз, включая будущие, с оценкой «начнётся через»
- У каждой привычки раскрывается блок «Откуда эти сроки». У курения, алкоголя и
  марихуаны за фазами клинические данные; у скроллинга и порно их нет, и текст
  говорит об этом прямо. Поэтому **графика тяги у них нет** — рисовать кривую
  без данных значило бы обесценить те, что построены на исследованиях

### История
- Лента всех событий, сводка (лучшая серия / обеты / пережитые тяги)
- Гистограмма «когда тянет» по часам — от 5 записей

### «Тянет» (SOS)
- Дыхание 4-7-8 с анимированным кругом
- Что на кону: серия, фаза, аскеза
- Каждое нажатие пишется в историю

### Производительность и доступность
- Один rAF-цикл: секунда — полное обновление, 10 Гц — тяга, кадр — только секундная полоса
- Запись в DOM только при изменении значения
- Пауза в фоне (`visibilitychange`)
- `prefers-reduced-motion`, `aria-label`, зум не заблокирован
- Service worker: network-first для HTML, stale-while-revalidate для остального

## Тесты

```bash
node askeza2/tests/run.mjs
```

309 проверок: чистые функции, все экраны, оба архетипа, аскезы, вехи, срывы,
режим сна (отметки, серия, пропуски, календарь, статистика), перенос из v1,
экспорт/импорт, XSS, устойчивость к битым данным, доступность.
Скриншоты кладутся в `askeza2/tests/shots/` (не коммитятся).

**Перед каждым коммитом прогонять тесты.**

## Версионирование

При **каждом** изменении:

1. Поменять версию в `askeza2/index.html` — константа `VERSION`
2. Поменять версию в `CLAUDE.md` — строка `**Текущая версия**` выше
3. Прогнать тесты
4. Запушить (`git add -A && git commit -m "vX.Y ..." && git push`)

Схема: `v[major].[minor]`.

# askeza 1 — заморожена

**Версия: `v1.4.0`**, файл `index.html` в корне репозитория.

Работает как раньше, данные лежат в `askeza_data`. Не изменять: askeza 2 читает
её хранилище для переноса и рассчитывает на то, что формат не менялся.

в одометре, три параллельные системы прогресса, ~200 строк мёртвого кода.
